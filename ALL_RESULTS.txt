  Val mAP50:       0.0513

  mAP50:      0.043
  mAP50-95:   0.013
  Precision:  0.114
  Recall:     0.042

PER-CLASS TEST BREAKDOWN:
  Class             Precision   Recall    F1      AP50    AP50-95
  ---------------------------------------------------------------
  benign_calc       0.098       0.017     0.029   0.023   0.007
  malignant_calc    0.129       0.067     0.089   0.063   0.020

INFERENCE SPEED:  48.2 ms/image (20.7 FPS)

KEY FINDINGS — CRITICAL NEGATIVE RESULT:
  CLAHE HURTS PERFORMANCE:
    Exp 7 (no CLAHE): mAP50 = 0.070
    Exp 8 (CLAHE):    mAP50 = 0.043  → 39% WORSE

  Per-class comparison:
    benign_calc:    Exp7=0.060  vs  Exp8=0.023  → 62% worse with CLAHE
    malignant_calc: Exp7=0.080  vs  Exp8=0.063  → 21% worse with CLAHE

  Early stop at epoch 55 (vs 121 for Exp7) shows CLAHE prevents convergence.

  WHY CLAHE HURTS:
  - CBIS-DDSM images are already well-preprocessed JPEGs
  - CLAHE distorts subtle pixel-level texture features YOLO uses for calcs
  - Local contrast changes disrupt pretrained COCO weight feature maps
  - Calc detection depends on precise intensity patterns → CLAHE destroys them

  PAPER VALUE: This negative result is publishable.
  "CLAHE preprocessing, commonly applied in medical imaging pipelines,
   is demonstrably harmful for YOLO11-based calcification detection on
   CBIS-DDSM (mAP50: 0.070 → 0.043, −39%). This finding saves future
   researchers from misapplying CLAHE to similar detection pipelines."

EXPERIMENT 13 / 14 — BATCH=1 BatchNorm FAILURE (ABLATION)
================================================================

STATUS:       FAILED (documented as negative ablation result)
DATE:         June 8, 2026
PURPOSE:      Attempt to push specialists higher by RAISING input
              resolution (mass 1024px, calc 1280px) with AutoBatch.

WHAT HAPPENED — UNINTENDED batch=1:
  At these resolutions on the Tesla T4 (14.9GB), Ultralytics
  AutoBatch (batch=-1) OOM'd at batch>=2 and silently fell back
  to batch=1:
    - Mass  @1024px: OOM at batch=4 -> settled batch=1 (4.46G/31%)
    - Calc  @1280px: OOM at batch=4 AND batch=2 -> settled batch=1

  batch=1 computes BatchNorm statistics from a SINGLE image each
  step = pure noise. The detector never converges: training loss
  falls normally while validation mAP oscillates and stalls.

RESULTS (FAILED):
  Exp 13 (Mass, 1024px, batch=1):
    Val mAP50 stalled ~0.10-0.165 (peak ep62), run aborted ep108
    vs Exp 6 baseline 0.447  ->  ~-63% (catastrophic)

  Exp 14 (Calc, 1280px, batch=1):
    Test mAP50 = 0.1846   (P=0.3032  R=0.4205  mAP50-95=0.0911)
      benign_calc    AP50 = 0.2007
      malignant_calc AP50 = 0.1685
    vs Exp 12 baseline 0.3486  ->  -47.1% (catastrophic)

ROOT CAUSE (single sentence for paper):
  "Increasing input resolution beyond the point where a batch of
   >=8 images fits in GPU memory is counter-productive: the
   resulting batch=1 training destroys BatchNorm statistics and
   collapses detection accuracy. A real batch size is more
   important than raw resolution on this hardware."

FIX APPLIED (Exp 13 v2 / Exp 14 v2):
    - Mass: imgsz 1024->640, batch 1->16
    - Calc: imgsz 1280->768, batch 1->8
    - mosaic 0.0->1.0 (re-enabled), lr0 0.0005->0.001,
      warmup 10->5, +TTA (augment=True) at test

CALC v2 RESULT (CONFIRMED WIN — June 9, 2026):
    YOLOv8l, 768px, batch=8, mosaic=1.0, TTA at test.
    150 epochs, 3.9h. Best val mAP50 = 0.4629 (epoch 116).
    TEST mAP50 = 0.3837  (+10.1% vs Exp 12 baseline 0.3486)
    TEST mAP50-95 = 0.3783   P = 0.5671   R = 0.5244
      benign_calc    P=0.6114 R=0.3628 AP50=0.3233 AP50-95=0.3227
      malignant_calc P=0.5227 R=0.6861 AP50=0.4442 AP50-95=0.4339
    Recovery from the failed batch=1 run (0.1846) = +108%.
    Weights: exp14_yolov8l_calc_final/runs/yolov8l_calc_final/weights/best.pt

MASS v2 RESULT (640px mosaic=1.0): FAILED — test mAP50=0.2113.
    Cause: early-stopped (ep117) BEFORE close_mosaic (ep135);
    mosaic crushed mass mAP50 (mAP50-95=0.180 = baseline, so the
    model was fine; only mAP50 suppressed). Mass HATES mosaic.
CALC v3 RESULT (NEW BEST — June 9, 2026):
    YOLOv8l, 1024px, batch=6, mosaic=1.0, TTA. 150 epochs, 6.6h.
    TEST mAP50 = 0.4024  (+15.4% vs Exp 12 baseline 0.3486; beats v2 0.384)

      malignant_calc P=0.5203 R=0.6934 AP50=0.4799 AP50-95=0.4709
    => CALC SPECIALIST = 0.4024. Resolution (768->1024) helped.
    Weights: exp14_yolov8l_calc_final/runs/yolov8l_calc_final/weights/best.pt (v3)

MASS v4 RESULT (1024px batch=8 mosaic=0): FAILED — test mAP50=0.2165.
